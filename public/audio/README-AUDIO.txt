PANITIA HUB RT03 — INSTRUMENTAL BERANDA

Taruh satu file instrumental yang Anda punya izin penggunaannya di folder ini:

public/audio/indonesia-raya-instrumental.mp3

Persyaratan:
- Format MP3 (audio/mpeg), nama file persis seperti di atas.
- Gunakan rekaman instrumental berizin untuk ditampilkan secara publik.
- Jangan unggah rekaman yang tidak memiliki hak distribusi.
- Tidak perlu mengubah file PHP/Blade/CSS/JS; refresh beranda setelah file tersedia.
- Pemutar berada pada sisi teks hero Beranda, di bawah tombol Jadwal/Lomba.
- Pengunjung harus menekan Putar; browser umumnya membatasi autoplay bersuara.
- Pemutaran berhenti saat pindah dari Beranda (satu halaman).
- Jika file belum dipasang, kartu menampilkan 'Instrumental segera hadir'.
- Untuk distribusi ke GitHub, pastikan Anda memiliki hak atas rekaman.
